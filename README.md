## AI/ML Projects 🤖
- **[LLM Logic](https://github.com/sasidharJasty/KB)** — [Live Demo](https://llm-logic.vercel.app/)
  A neuro-symbolic AI framework bridging LLMs with deterministic reasoning engines, using forward/backward chaining for first-order logic and LangGraph-based multi-agent workflows.
  **Technologies:** Python, LangChain, LangGraph, First-Order Logic, AI Agents 🧠
- **[ExoNet](https://github.com/sasidharJasty/ExoNet)** — [Live Demo](https://exo-net.vercel.app/)
  An end-to-end deep learning pipeline classifying exoplanet transits from raw stellar data with a custom PyTorch neural network.
  **Technologies:** Python, PyTorch, Deep Learning, Astronomy 🪐
- **[LightCurves](https://github.com/sasidharJasty/LightCurves)**
  A machine learning toolkit for analyzing time-series astronomical light curves to help identify exoplanets.
  **Technologies:** Python, Pandas, NumPy, Scikit-Learn, Data Science ✨
- **[CycleGAN](https://github.com/sasidharJasty/CycleGAN)**
  A PyTorch-based CycleGAN for unpaired image-to-image translation, with custom generator/discriminator networks tuned to avoid mode collapse.
  **Technologies:** Python, PyTorch, GANs, Computer Vision 🎨
